# Sabre Codex — UI Kit

A catalogue / browse interface for the full figure index. Left sidebar with clan filters, center grid of figure cards, right detail drawer showing inscription + metadata for the selected figure.

**Screens**
- `index.html` — codex landing with selected figure open in the right drawer.

**Components**
- `CodexNav.jsx` — top nav with breadcrumb
- `Sidebar.jsx` — clan filter sidebar with counts
- `FigureGrid.jsx` — main grid of figure cards
- `FigureDetail.jsx` — right-side detail drawer
