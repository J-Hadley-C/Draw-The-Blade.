# Dojo Sabre — Showcase UI Kit

The canonical **3D rotating image gallery** wrapped in a proper product chrome. Faithful to the source `ROTATION_3D/` CSS (20s linear rotation, 10 panels at 45° each, 4px double black border, box-reflect), with added nav, hero caption rail, figure index, and pause control.

**Screens**
- `index.html` — landing / showcase with the rotating cylinder and full chrome.

**Components**
- `Nav.jsx` — top nav with wordmark, links, CTA
- `Hero.jsx` — hero copy column + 3D carousel stage (right)
- `Carousel3D.jsx` — the rotating cylinder, copied from source CSS
- `FigureRail.jsx` — below-the-fold caption rail with all 11 figures
- `Footer.jsx` — ceremonial footer with kanji and copyright rule
