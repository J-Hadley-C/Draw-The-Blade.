# Khen Fu — Draw The Blade

## Product Purpose
Plateforme de vente de beats musicaux (trap, drill, R&B, afrobeat, kompa). L'artiste Khen Fu vend des licences de beats instrumentaux à des rappeurs et artistes. Interface publique (showcase carousel 3D + catalogue) + dashboard admin privé pour gérer le catalogue.

## Register
product

## Users
- **Publique** : rappeurs, artistes émergents et confirmés cherchant des instrumentales, 18–35 ans, habitués des plateformes de type BeatStars/Airbit.
- **Admin** : Khen Fu lui-même — usage solo, gestion du catalogue, lecture des messages de contact.

## Brand
- **Nom** : Khen Fu · Draw The Blade
- **Esthétique** : dark cinematic neo-samurai / shinobi. Sombre, cérémoniel, percutant.
- **Ton** : impératif, troisième personne, sans émoji, laconique. Kanji comme accents visuels.
- **Couleurs** : crimson (#a3161f), ember (#e09620), ink (backgrounds profonds). Pas de purple, pas de gradients lumineux.
- **Typographie** : Cinzel ALL CAPS pour les titres (display), mono pour les labels et métadonnées, sans-serif pour le body.
- **Motion** : lent, rituel. 20s+ rotations. Entrées douces. Zéro bounce.

## Anti-references
- SaaS générique blanc/bleu
- BeatStars (couleurs neon, layout encombré)
- Glassmorphism décoratif
- Gradient text
- Hero-metric template (grand chiffre + gradient accent)

## Strategic Principles
1. Dark mode absolu — jamais de light mode.
2. Image tiles : 4px double-border noir + box-reflect.
3. Accents crimson + ember uniquement.
4. Copie : cérémoniale et brève.
